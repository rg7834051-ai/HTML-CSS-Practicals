
# Lab 14 – CSS Grid

## Aim
To understand CSS Grid layouts, responsive galleries and grid template areas.

## Task 1: Basic CSS Grid
Created `grid-first.html` with:
- Six boxes
- Three equal columns using 1fr
- 12px gap between boxes

## Task 2: Responsive Photo Gallery
Created `gallery.html` with:
- Six photo boxes
- auto-fill and minmax() for responsive columns
- 10px gap

## Task 3: Dashboard Layout
Created `dashboard-areas.html` with:
- Two columns: 200px and 1fr
- Header and Footer across both columns
- Sidebar on the left
- Main content on the right
