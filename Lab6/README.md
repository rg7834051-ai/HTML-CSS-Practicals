
# Lab 6 – Types of HTML Lists

## Aim
To create unordered lists, ordered lists with nested lists, and description lists using HTML.

## Task 1: Shopping List
Created an unordered list containing:
- Notebook
- Pen
- Bag

## Task 2: Canteen Menu

- Samosa
- Sandwich
  - Cheese
  - Vegetable

## Task 3: Library FAQ
Created a description list containing two questions and their answers using HTML `<dl>`, `<dt>`, and `<dd>` tags.
