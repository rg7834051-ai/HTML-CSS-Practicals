
# Lab 13 – Flexbox

## Aim
To understand CSS Flexbox layout, alignment and wrapping.

## Task 1: Flexbox Navigation
Created `nav-flex.html` using:
- display: flex
- Dark navigation background
- White navigation links

## Task 2: Centered Cards
Created `centred-cards.html` with three pricing cards:
- Starter – ₹199
- Standard – ₹349
- Premium – ₹499

Used justify-content and align-items for centering.

## Task 3: Wrapping Cards
Created `wrapping-cards.html` with four stationery cards:
- Notebook – ₹60
- Pen – ₹15
- Bag – ₹350
- Book – ₹120

Used flex-wrap to move cards to the next line when space is limited.
