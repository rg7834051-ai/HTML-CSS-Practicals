
# Lab 8 – Sign-Up Forms and Choices

## Aim
To create HTML forms using input fields, radio buttons, dropdown menus and required attributes.

## Task 1: Sign-Up Form
Created a form with Full Name, Email and Password fields using the POST method and thanks.html as the action.

## Task 2: Student Choices
Created gender radio buttons (Female and Male) and a course dropdown (BCA and B.Tech).

## Task 3: Required Sign-Up Form
Created Full Name and Email fields with required attributes, a placeholder and a Submit button.
