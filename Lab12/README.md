
# Lab 12 – Box Model, Cards and Scrolling

## Aim
To understand the CSS box model, card styling and overflow scrolling.

## Task 1: CSS Box Model
Created `box-model.html` with two boxes:
- First box uses content-box.
- Second box uses border-box.
- Both have 200px width, 20px padding and 5px border.

## Task 2: CSS Card
Created `card.html` with:
- Background color
- 2px border
- 12px border radius
- 16px padding
- Heading and paragraph

## Task 3: CSS Scrolling
Created `scroll.html` with:
- Fixed height of 120px
- Overflow set to auto
- Five paragraphs inside the scrollable box
