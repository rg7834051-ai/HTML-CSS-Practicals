
# Lab 9 – HTML Tables

## Aim
To create HTML tables using captions, table headings, table body, table footer and accessibility attributes.

## Task 1: Basic Marks Table
Created a table showing Maths and Science marks of Asha, Rohan and Neha.

## Task 2: Table with Class Average
Created a table showing marks of Asha and Rohan with a footer containing class averages:
- Maths: 71
- Science: 77.5

## Task 3: Accessible Table
Created an accessible marks table using `scope="col"` for column headings and `scope="row"` for row headings.
